# Farmer Registration Management System

A Full Stack Farmer Management Application built using Spring Boot, MySQL, HTML, CSS, and JavaScript.

## Features

- Add Farmer
- View Farmers
- Update Farmer
- Delete Farmer
- Search Farmers
- Form Validation
- Responsive UI
- MySQL Database Integration

## Technologies Used

### Backend
- Java
- Spring Boot
- Spring Data JPA
- MySQL

### Frontend
- HTML
- CSS
- JavaScript
